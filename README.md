# Turbofan Engine - Remaining Useful Life (RUL) Prediction

This repository contains code and results for predicting the Remaining Useful Life (RUL) of aircraft turbofan engines using NASA turbofan datasets (FD001–FD004). The code implements data loading, preprocessing, Partial Least Squares (PLS) regression, Kernel PLS (KPLS) with several kernels, and hyperparameter optimization.
